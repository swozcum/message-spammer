# 🚀 Mesaj Spam (Message Spammer)

Discord DM veya kanala self hesap ile otomatik mesaj gönderen Electron masaüstü aracıdır.

## ✨ Özellikler

| Özellik | Açıklama |
|---------|----------|
| 📨 DM Desteği | Kullanıcı ID ile özel mesaj spam |
| 💬 Kanal Desteği | Kanal ID ile mesaj spam |
| ∞ Sınırsız Mod | Mesaj sayısı 0 girilirse sürekli gönderir |
| 📊 Canlı İstatistik | Gönderilen / hedef / süre anlık güncellenir |
| 🛑 Anında Durdurma | İstediğin zaman işlemi sonlandır |
| 🔔 Bildirim | İşlem bitince Windows bildirimi |

## 🛠️ Kurulum

```bash
npm install
```

Kurulum tamamlandıktan sonra `başlat.bat`'ı çalıştırman yeterli.

## 📖 Kullanım

1. **Hesap Tokeni** alanına kullanılacak hesabın tokenini yaz.
2. **Hedef Tipi** seç: DM veya Kanal.
3. **Hedef ID** alanına kullanıcı veya kanal ID'sini yaz.
4. **Mesaj** alanına gönderilecek mesajı yaz.
5. **Mesaj Sayısı** alanına adet yaz (0 = sınırsız).
6. **Spam Başlat** butonuna bas.

> ⚠️ Sınırsız modda işlemi durdurmak için **Durdur** butonunu kullanın.
